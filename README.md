# SparkleWash - Car Washing Service Website

A responsive frontend for a car washing service. Visitors can browse services, see pricing, book a wash through a popup form, and find contact details.

**Live site:** https://YOUR-USERNAME.github.io/car-wash-website/

## Features

- Sticky navbar with hover effects and a mobile hamburger menu
- Hero section with a call-to-action button
- Services section built with CSS Grid and hover scale animation
- Pricing section with three plans
- Booking modal with form validation (name, email, date)
- Footer with contact info and Font Awesome social icons
- Mobile-first, responsive layout using Flexbox, Grid and media queries

## Tech Stack

HTML5, CSS3 (Flexbox, Grid, Media Queries), vanilla JavaScript, Font Awesome. Deployed with GitHub Pages.

## Run Locally

Open `index.html` in any browser. No build step is needed.

## Deployment

Push to GitHub, then go to Settings > Pages, choose the `main` branch and the `/ (root)` folder, and save.
